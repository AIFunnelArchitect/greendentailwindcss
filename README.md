# GreenDen Practice Project

GreenDen is a **practice website project** I built while learning **Tailwind CSS**. The project helped me understand how to use utility-first CSS classes to create and style a modern website without writing large amounts of custom CSS.

### What I Learned

* Using **Tailwind CSS** for website styling
* Building layouts using Tailwind utility classes
* Working with spacing, colors, typography, and responsive design
* Creating reusable and structured webpage sections
* Organizing a front-end project
* Using **Git and GitHub** to manage and publish my project

### Technologies Used

* **HTML5**
* **Tailwind CSS**
* **Git & GitHub**

This is a **practice project** created to strengthen my front-end development and Tailwind CSS skills.
